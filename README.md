# NFTGalleryPro

NFTGalleryPro is a high-performance, cloud-based platform providing real-time data processing and auto-scaling for dynamic NFT asset management.

With NFTGalleryPro, you get a lightweight tool that stays out of your way.

**What you get**

- NFTGalleryPro is a high-performance, cloud-based
- platform providing real-time data processing
- and auto-scaling for dynamic NFT

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/NFTGalleryPro.git`
2. `cd NFTGalleryPro`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
